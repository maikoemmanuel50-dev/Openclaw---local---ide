# MapReveal — Zoom-Out + Stat Slam

Reusable map reveal template from Scene 07.

## File
`templates/blender/MapReveal.blend`

## Components
- Custom zoom-out camera (see `setup_cameras_and_render.py`)
- Glowing center point (Nairobi pulse)
- Dim regional markers
- Center-screen stat text (`97%` in Ep01)

## Keyframes
| Frame | Action |
|-------|--------|
| 0-120 | Tight zoom, pulse intensifies |
| 360 | Stat slams center (`97%`) |
| 120-600 | Camera zoom-out reveals full map |
| 660+ | Regional markers blink dim |
